# ChaseTag

Unreal Engine / C++ / Blueprint を使用して制作した、追跡アクションゲームのプロトタイプです。

プレイヤーがステージ上を移動しながら、ワープ、ターザンロープ、落下床、回転床、ランダム移動床などのギミックを利用して遊ぶことを想定したゲームです。

本プロジェクトでは、既存アセットを活用しつつ、ゲーム内ギミックやUI表示、ステージ構成を自分で設計・実装しました。

## 概要

ChaseTag は、アクションゲームの移動感やステージギミックを検証するために制作したプロトタイプです。

プレイヤーがステージ上を移動しながら、さまざまな足場や移動手段を使って立ち回ることを想定しています。

特に、単純なステージ移動だけでなく、

- 触れると一定時間後に落下する床
- 回転する床
- ランダムに移動する床
- ワープポイント
- ターザンロープによる移動

などを実装し、アクションゲームらしい操作感を出すことを目指しました。

## 実装した機能

### ワープ機能

特定のエリアにプレイヤーが入ると、指定した別地点へワープする機能です。

ワープ時にはプレイヤーの移動を停止し、連続で何度もワープしないようにクールタイム処理を入れています。

また、ターザン機能で使用しているプレイヤー体力と連動させ、一定以上の体力がある場合のみワープできるようにしました。

### ターザンロープ機能

Cable Component を使用して、プレイヤーがロープにつかまり、勢いを利用して移動できるギミックを実装しました。

プレイヤーがロープの判定エリアに入るとロープにつかまり、エリアから離れるとロープを離す処理を行います。

ロープ使用中はプレイヤーの体力を消費し、体力がなくなると自動的にロープを離すようにしています。

### プレイヤー体力UI表示

プレイヤーの残り体力を画面上に表示するUIを実装しました。

ターザンロープやワープ機能と連動しており、体力の増減がリアルタイムで画面に反映されるようにしています。

### 落下床

プレイヤーが床に乗ると、一定時間揺れたあとに落下する床を実装しました。

落下前に床を揺らすことで、プレイヤーに「この床は危険」という予兆が伝わるようにしています。

落下後は一定時間後に初期位置へ戻るようにし、繰り返し使えるギミックとして設計しました。

### 回転床

常に回転し続ける床を実装しました。

Tick処理で毎フレーム回転を加えることで、プレイヤーの移動を妨害するステージギミックとして使用できるようにしています。

### ランダム移動床

一定距離を移動したあと、ランダムに移動方向を変える床を実装しました。

移動範囲の端に到達した場合は方向を調整し、ステージ外へ移動し続けないように制御しています。

### スタートカウントダウン機能

プレイヤーが開始エリアに入ると、ゲーム開始前のカウントダウンが始まる機能を実装しました。

カウントダウンUIを表示し、開始音やゲーム開始後のタイマー表示も管理しています。

### マップ制作

SuperGrid Starter Pack などを使用し、各ギミックを配置したステージを制作しました。

単にアセットを配置するだけでなく、ワープ、ロープ、移動床、落下床などのギミックを組み合わせ、プレイヤーが移動しながら遊べる構成を意識しました。

## 工夫した点

### 既存アセットを活用しながら、自作ギミックを追加

Advanced Locomotion System V4 を使用することで、キャラクター移動の基盤を確保しました。

そのうえで、ゲームとしての独自性を出すために、ワープ、ターザンロープ、落下床、回転床、ランダム移動床などのギミックをC++で実装しました。

### UIとゲームギミックの連動

プレイヤー体力をUIに表示し、ターザンロープやワープの使用によって体力が変化するようにしました。

これにより、単なる移動ギミックではなく、リソース管理を含むゲーム性を持たせています。

### プレイヤーに予兆を伝える落下床

落下床は、触れた瞬間にすぐ落ちるのではなく、一定時間揺れてから落下するようにしました。

これにより、プレイヤーが危険を認識して行動できるようにしています。

### 複数のステージギミックを組み合わせたマップ設計

ワープ、ロープ、移動床、落下床などを単体で作るだけでなく、マップ上に配置して実際に遊べる形にしました。

アクションゲームとして、移動ルートやタイミングを考える面白さを出すことを意識しました。

## 主なスクリプト

### FallingPlatform

プレイヤーが触れると一定時間後に落下する床です。

主な処理：

- プレイヤーとのOverlap判定
- 落下前の揺れ演出
- 一定時間後の物理シミュレーション有効化
- 床のリセット処理
- 落下時のサウンド再生

### GameStarter

ゲーム開始時のカウントダウンとタイマー表示を管理するクラスです。

主な処理：

- 開始エリアへのOverlap判定
- スタートカウントダウン
- ゲーム開始処理
- UI表示の更新
- 効果音の再生

### RandomPlatform

ランダムに方向を変えながら移動する床です。

主な処理：

- Tickによる床の移動
- 一定距離移動後の方向変更
- ステージ範囲外に出ないための方向制御

### RotationFloor

常に回転し続ける床です。

主な処理：

- Tickによる回転処理
- 回転速度の調整

### TarzanRope

プレイヤーがつかまって移動できるターザンロープです。

主な処理：

- Cable Component の設定
- プレイヤーのOverlap判定
- ロープへの接続 / 解除
- プレイヤーへの力の加算
- 体力の消費と回復
- 体力UIの更新

### WarpActor

プレイヤーを指定地点へ移動させるワープ機能です。

主な処理：

- ワープエリアへのOverlap判定
- 指定したActor位置への移動
- ワープ後の移動停止
- 連続ワープ防止
- プレイヤー体力の消費
